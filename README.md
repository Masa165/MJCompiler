# MicroJava Compiler

A complete compiler implementation for a MicroJava-based programming language, developed in Java using JFlex and CUP.

The compiler implements the full compilation pipeline, from lexical analysis and LALR parsing through AST construction, semantic analysis, and MicroJava bytecode generation.

## Features

- Lexical analysis with **JFlex**
- LALR parsing with **CUP**
- Automatically generated **Abstract Syntax Tree (AST)**
- Symbol table and scope management
- Semantic analysis
- Type checking
- Expression and designator validation
- Method and parameter checking
- Array handling
- Control-flow validation
- MicroJava bytecode generation
- Bytecode execution using the MicroJava runtime
- Bytecode disassembly for inspection and debugging
- Extended MicroJava language features

## Extended Language Features

The compiler extends the standard MicroJava language with additional constructs, including:

- `findAny` — iterates through a one-dimensional array of a built-in type and returns `true` if an element matches the value of the given expression; otherwise, it returns `false`.

```text
found = numbers.findAny(target);
```

- `expr1 ?? expr2` — returns `expr1` if it is non-zero; otherwise, returns `expr2`.

```text
x = a ?? b;

// If a != 0, result is a.
// If a == 0, result is b.
```

- `designator ?= expr` — assigns `expr` to `designator` only if `designator` is zero; otherwise, its value remains unchanged.

```text
x ?= 10;

// If x == 0: x becomes 10.
// If x != 0: x remains unchanged.
```

- `designator[^expr]` — returns the sum of the last `expr` elements of the array referenced by `designator`.

```text
sum = arr[^3];

// Equivalent to arr[n-3] + arr[n-2] + arr[n-1]
```


## Compiler Pipeline

```text
MicroJava source
       │
       ▼
┌─────────────────────┐
│   Lexical Analysis  │
│       JFlex         │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│       Parsing       │
│        CUP          │
│      LALR Parser    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│    AST Generation   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Semantic Analysis  │
│   + Type Checking   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│   Code Generation   │
│  MicroJava Bytecode │
└──────────┬──────────┘
           │
           ▼
      `.obj` file
           │
           ├──────────────► MicroJava Runtime
           │
           └──────────────► Bytecode Disassembler
```
